# AWS Cloud Sprint

Hands-on AWS cloud engineering work: study notes, labs, and infrastructure built with Terraform, alongside preparation for the AWS Solutions Architect Associate (SAA-C03) certification.

## Focus

- AWS core services: networking, compute, storage, IAM
- Infrastructure as code with Terraform
- Containers and CI/CD
- Portfolio projects deployed on AWS

## Structure

- `notes/` - study notes
- `labs/` - hands-on lab work
- `terraform/` - infrastructure as code
- `scripts/` - helper scripts
- `project/` - portfolio projects
- `docs/` - documentation
- `adr/` - architecture decision records
